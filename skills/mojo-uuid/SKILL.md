# mojo-uuid

Use for UUID parsing, byte encoding, namespaced IDs and v4/v6/v7/v8 generation.
Not for UUID1/2, SafeUUID, or hardware MAC lookup.

## Install

Clone with a mojo-hashlib checkout beside it. Requires Mojo >=1.2.0,<1.3.
From the clone: `mojo run -I src -I ../mojo-hashlib/src examples/quickstart.mojo`.

## Main calls

- `UUID(text)` parses braces, URN, compact or hyphenated forms.
- `value.__str__()` returns canonical lowercase text.
- `uuid3(namespace, name)` and `uuid5(namespace, name)` hash names.
- `uuid4()` uses system random bytes.
- `UUID7Generator.next()` generates a monotonic sequence on one instance.
- `Dict[UUID, V]`, `Set[UUID]`, `print(uuid)` and `String(uuid)` work; `uuid.hex()`, `uuid.urn()` and `uuid.bytes()` give other forms.

## Gotchas

Constants use `materialize[NAMESPACE_DNS]()`.
Byte input uses `UUID(Span(data), little_endian=True)` for bytes_le.
An omitted version preserves bits; explicit version 0 raises UUIDError.
Catch UUIDError; compare its kind and message separately.
Reuse UUID6Generator/UUID7Generator for monotonicity. One-shot helpers share no state.
Names use UTF-8. Parsing follows CPython `int()`: surrounding spaces, `0x`, underscores and Unicode digits are accepted.
`UUID.from_int(text)` takes decimal text.
